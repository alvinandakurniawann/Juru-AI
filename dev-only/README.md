# dev-only

Isi simulasi USB ada di `../usb-drive/`. Folder ini tidak ikut ke flashdisk.

- `tests/` pengujian otomatis Fase 1 (stdlib saja, tanpa pytest).
- `simulator/` mock untuk test tanpa menyentuh desktop asli (Fase 2).
- `scripts/` skrip bantu development.
- `docs/` catatan per fase.
- `development-config/` konfigurasi khusus mesin development.
- `build/` hasil rakitan menuju USB.
